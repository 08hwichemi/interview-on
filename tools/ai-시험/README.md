# 노트북에서 작은 AI 로 질문 뽑기 — 시험 화면

앱 본체와 따로 있는 시험 페이지입니다. 「규칙으로 뽑은 질문」과 「노트북 안에서 돌리는 작은 AI 가 만든 질문」을
나란히 놓고 견줍니다. 쓸 만하면 그때 앱의 「📄 생기부에서 뽑기」 안에 선택 단추로 넣습니다.

열기: `https://08hwichemi.github.io/interview-on/tools/ai-시험/` (main 에 올라간 뒤)

## 어떻게 돌아가는가

- **WebLLM** 이라는 도구로 브라우저 안에서 언어 모델을 돌립니다. 서버가 없고, 열쇠도 없고, 돈도 안 듭니다
- 모델 파일(1.5B ≈ 1GB · 3B ≈ 2GB)은 **Hugging Face** 에서 받아 브라우저 캐시에 둡니다.
  우리 저장소에도 Supabase 에도 올리지 않습니다. 한 노트북에 한 번만 받습니다
- 생기부 글은 노트북 밖으로 나가지 않습니다 — 앱의 원칙 그대로입니다
- 자르기(영역·학년·과목)와 규칙 질문은 `assets/js/saenggibu.js` 를 그대로 씁니다

## 조건

- 크롬 · 엣지 최신판 (WebGPU 가 있어야 합니다. 사파리는 안 됩니다)
- 램 8GB → 1.5B, 램 16GB → 3B. 내장 그래픽이면 느릴 뿐 돌긴 합니다
- 묶음 하나에 30초~1분쯤 걸립니다. 3년치를 한 번에 돌리는 용도는 아닙니다

## 첫 시험 결과 (2026-10-05)

- 램 16GB · **내장 그래픽(intel gen-12lp) · 그래픽 메모리 한도 2048MB** 노트북
- 3B(약 2GB)는 **받아지긴 하는데(250초) 질문을 만들려는 순간 모델이 내려갑니다** —
  한도와 모델 크기가 같아서 작업 공간을 더 잡을 자리가 없습니다
  (WebLLM 오류 «Model not loaded before trying to complete ChatCompletionRequest»)
- → 내장 그래픽 노트북은 **1.5B** 로 갑니다. 화면에서 이 경우를 알아채 한국어로 안내합니다

## 아직 모르는 것

- 이 시험 화면은 작업 환경에서 외부 사이트가 막혀 있어 **직접 돌려 보지 못했습니다.**
  선생님 노트북에서 처음 눌러 보는 것이 첫 시험입니다. 안 되면 「모델 받기」 옆에 뜨는 글을 그대로 알려 주세요
- 작은 모델은 깊이가 얕고 가끔 없는 얘기를 지어냅니다. «초안» 으로 보고 선생님이 고릅니다
