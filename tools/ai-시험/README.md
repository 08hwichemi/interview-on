# 노트북에서 작은 AI 로 질문 뽑기 — 해 보고 접음 (2026-10-05)

지금 이 폴더에는 **「받아 둔 AI 모델 지우기」 페이지만** 남아 있습니다.
시험 화면 자체는 지웠습니다 (깃 기록 `e8212bd` 에 있습니다).

지우기 페이지: `https://08hwichemi.github.io/interview-on/tools/ai-시험/`
— 시험해 본 노트북마다, 쓴 브라우저마다 한 번씩 누릅니다. 더 지울 노트북이 없으면 이 폴더도 지워도 됩니다.

## 무엇을 해 봤는가

WebLLM 으로 브라우저 안에서 작은 언어 모델(Qwen2.5 3B · 1.5B)을 돌려, 규칙으로 뽑은 질문과 나란히
견주는 시험 화면을 만들었습니다. 돈이 안 들고 생기부가 노트북 밖으로 안 나가는 길이었습니다.

## 왜 접었는가

선생님 노트북(램 16GB · 인텔 내장 그래픽 gen-12lp · 그래픽 메모리 한도 2048MB · 윈도우 11 새로 깖):

- 3B(≈2GB)는 받아지지만(250초) 질문을 만들려는 순간 그래픽 장치가 떨어짐 — «Model not loaded …»
- 한 번 떨어진 장치는 브라우저를 전부 닫기 전까지 떨어진 채로 남음 — «DXGI_ERROR_DEVICE_REMOVED»
- 브라우저를 새로 연 뒤 **1.5B 로도 10초 만에 떨어짐** — «Object has already been disposed»
- 메모리가 아니라 **내장 그래픽이 WebGPU 계산을 버티지 못하는 것.** 다른 선생님 노트북은 더 낮은 사양

→ 학교 전체에서 쓸 수 없는 방법입니다. 그래픽 카드가 따로 있는 컴퓨터가 생기면 되살려 볼 수 있습니다.

## 남은 길 (돈 안 드는 것)

- «AI 에게 물어볼 글 복사» 단추 — 잘라 둔 기록 + 지시문을 복사해 선생님이 직접 ChatGPT·클로드에 붙여넣기
- 기출 질문 2,360줄에서 질문 틀을 뽑아 규칙 키우기 — 내용은 모르니 천장이 낮습니다
