## 정해진 것 (다시 논의하지 말 것)

- **생기부는 브라우저에서만 읽고 버립니다.** 서버에 원문을 올리지 않습니다
- **질문 추출은 규칙 기반**으로 시작. AI 는 나중에 선택지로
- **이메일을 쓰지 않습니다.** 학생=학번, 교사=이름. 계정은 관리자가 전부 만듭니다
- **계정을 만들고·되돌리고·지우는 일은 관리자만** 합니다. 교사 화면에는 그 길이 없습니다
- **초기 비밀번호는 몫마다 하나씩** — 학생 `111111`, 선생님 `123456`. 첫 로그인 때 반드시 바꿉니다
- **채점표는 공통 평가요소 + 면접 태도 + 기록 확인** 을 한 표에
- 화면은 **왼쪽 목록 : 오른쪽 내용 = 2 : 8**
- **수시 지원 자료는 서버끼리만 주고받습니다.** 저쪽 방 열쇠를 브라우저에 넣지 않습니다
  (자세한 것은 [할-일.md](할-일.md) 의 「수시 자료는 어떻게 오는가」)

## 🚨 새 세션이 가장 먼저 알아야 할 것

### 1. 올릴 때는 **두 곳 모두**에 올려야 합니다

GitHub Pages 가 내보내는 것은 **`main`** 입니다.
작업 branch(`main-2w1cgu`)에만 올리면 **선생님 화면은 판이 그대로입니다.**
실제로 한 번 「버전이 안 바뀌는데?」 하고 걸렸습니다.

```bash
git push -u origin main-2w1cgu          # 작업 branch
git push origin main-2w1cgu:main        # 이게 있어야 실제로 올라갑니다
git fetch origin -q && git show origin/main:version.txt   # 확인
```

### 2. 판 번호는 손으로 고치지 마세요

```bash
python3 tools/판올리기.py 2026-09-18.9
```
`version.txt` · `BUILD_ID` · 파일 주소 44곳을 한꺼번에 맞춥니다.
셋 중 하나라도 어긋나면 「새로고침」을 눌러도 띠가 안 사라집니다.

### 3. 고친 뒤에는 브라우저로 직접 눌러 봅니다

`tools/화면-시험/` 에 검사가 들어 있습니다. [그 폴더의 README](../tools/화면-시험/README.md) 를 보세요.


(`git stash` 로 고친 것을 치우고 다시 돌려 보면 압니다).
