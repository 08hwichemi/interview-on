# 계정 구조

## 로그인 방법

**이메일은 쓰지 않습니다.** 계정은 관리자가 전부 만들고, 스스로 가입하는 길은 없습니다.

| | 아이디 | 로그인 후 가는 곳 |
|---|---|---|
| 학생 | 학번 (예: `20301`) | `index.html` — 모바일 앱 |
| 교사 | 이름 (예: `이용휘`) | `teacher/` — PC용 넓은 화면 |
| 관리자 | 이름 | `teacher/` (+ 계정 관리 권한) |

첫 로그인 때는 관리자가 준 초기 비밀번호를 쓰고, **반드시 본인 비밀번호로 바꾸게** 되어 있습니다 (`profiles.must_change_password`). 바꾸고 나면 관리자도 그 비밀번호를 알 수 없습니다.

## 한글 아이디가 되는 이유

서버(Supabase Auth)는 계정을 이메일 형태로만 구분하는데, 이메일 주소에는 한글을 쓸 수 없습니다. 그래서 아이디를 16진수로 바꿔 내부 주소를 만듭니다.

```
이용휘 (교사)  →  t ec9db4ec9aa9ed9c98 @9bf9d65d.interview-on.local
20301  (학생)  →  s 3230333031        @9bf9d65d.interview-on.local
                  ↑        ↑
              역할 구분   아이디의 16진수
```

앞의 `t` / `s` 가 교사와 학생의 공간을 갈라 놓기 때문에, 교사 이름과 학번이 어쩌다 같아도 부딪히지 않습니다. 이 주소는 화면에 절대 보이지 않습니다.

> ⚠️ 이 변환 규칙은 **두 곳**에 있습니다. 한쪽만 고치면 모든 로그인이 깨집니다.
> - `assets/js/auth.js` 의 `toInternalEmail()`
> - Edge Function `create-student-accounts` 의 `toInternalEmail()`

`.interview-on.local` 은 실제로 존재하지 않는 도메인입니다. 메일을 보내지 않으므로 상관없습니다. 참고로 이 도메인은 **일반 가입(signUp)으로는 거부**되고 관리자 API로만 만들 수 있는데, 계정을 관리자만 만들 수 있게 하려는 우리 정책과 맞아떨어집니다.

## 계정 만들기

Edge Function `create-student-accounts` 가 처리합니다. `service_role` 키가 필요한 작업이라 브라우저가 아닌 서버에서만 돕니다.

- 부른 사람이 교사/관리자인지 먼저 확인합니다
- **교사 계정은 관리자만** 만들 수 있습니다 (교사가 교사를 늘리지 못하게)
- 초기 비밀번호는 무작위 **숫자 6자리**. 학생이 받아적어 치기 쉬워야 하고, 어차피 첫 로그인 때 바꿉니다. `000000`, `123456` 처럼 한눈에 보이는 것은 피합니다
- 초기 비밀번호는 **응답으로 한 번만** 돌려주고 서버 어디에도 저장하지 않습니다
- 중간에 실패하면 만들다 만 계정을 되돌립니다

## 권한 (RLS)

| 테이블 | 학생 | 교사 | 관리자 |
|---|---|---|---|
| `reviews` `questions` `common_questions` | 읽기 | 읽기 | 읽기 |
| `profiles` | 본인만 | 같은 학교 읽기 | 같은 학교 전부 |
| `students` | 본인 행만 | 같은 학교 전부 | 같은 학교 전부 |

- **로그인하지 않으면 아무것도 읽히지 않습니다.** 확인: 비로그인 상태로 `reviews` 조회 시 `[]`
- 학생이 스스로 `role` 을 `admin` 으로 바꾸려 하면 트리거가 막습니다 (`private.profiles_guard`)
- RLS 판단용 도우미 함수(`is_admin`, `is_teacher`, `current_school_id`)는 `private` 스키마에 있습니다. `public` 에 두면 `/rest/v1/rpc/is_admin` 같은 주소로 바깥에 노출됩니다.

## 남은 보안 설정 하나

Supabase 대시보드 → Authentication → Policies 에서 **Leaked Password Protection** 을 켜면, 이미 유출된 적 있는 비밀번호(HaveIBeenPwned 대조)를 학생들이 쓰지 못하게 막을 수 있습니다. 코드로는 못 켜고 대시보드에서만 됩니다.
